How connections work

Three ways in, all of them yours

{% include "marketing/_icon.html" with name="key" %}

Your developer app, OAuth login

Facebook, Instagram, Threads, LinkedIn, TikTok, YouTube, Pinterest and Google Business Profile use an app you register with the platform. Paste its keys into the environment or the admin, and users connect with the familiar "Continue with…" flow.

{% include "marketing/_icon.html" with name="lock" %}

App password or API key

Bluesky connects with a handle and an app password; DEV.to with a personal API key. No developer registration, and both can be revoked from the platform at any time.

{% include "marketing/_icon.html" with name="globe" %}

Any Mastodon instance

Type the instance URL. {{ site_name }} registers its own OAuth application on that server automatically, so the Fediverse works without configuration.

{% include "marketing/_icon.html" with name="info" %}

Instagram, two ways. Connect through a linked Facebook Page (Business and Creator accounts), or directly with Instagram Login for professional accounts that have no Facebook Page at all. Personal Instagram accounts have no public API since Meta retired the Basic Display API; switching to a professional account is free and takes a minute in the Instagram app.

Per-platform details

The parts people usually ask about

The connect flow explains each platform's requirements as you go. A few worth knowing up front:

  • {% include "marketing/_icon.html" with name="check" %}LinkedIn supports personal profiles with any developer app, and company pages once LinkedIn approves the Community Management API. Company credentials cover both.
  • {% include "marketing/_icon.html" with name="check" %}TikTok publishes video through the Content Posting API and reports insights; comments and DMs are not exposed by TikTok's API.
  • {% include "marketing/_icon.html" with name="check" %}YouTube and Google Business Profile share one Google Cloud project. YouTube uploads videos and Shorts and reads comments and analytics.
  • {% include "marketing/_icon.html" with name="check" %}Pinterest publishes pins to a board you choose per post, with a destination link.
  • {% include "marketing/_icon.html" with name="check" %}Facebook and Instagram inbox use Meta webhooks for instant delivery, with a five-minute poll as the fallback.
  • {% include "marketing/_icon.html" with name="check" %}DEV.to publishes a title and Markdown body as an article, which makes it a good home for long-form companions to a social post.
