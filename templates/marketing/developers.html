Authentication

Workspace-scoped keys

Issue a key from Organisation → API Keys. Each key belongs to one workspace, can be allow-listed to specific social accounts, and carries a subset of the issuer's own permissions. Revocation is immediate.

  • {% include "marketing/_icon.html" with name="check" %}Permissions: create_posts, publish_directly, upload_media, view_analytics, use_inbox, reply_from_inbox. Missing one returns 403.
  • {% include "marketing/_icon.html" with name="check" %}Idempotency: post creation, media uploads and inbox replies accept an idempotency_key (or Idempotency-Key header) for safe retries.
  • {% include "marketing/_icon.html" with name="check" %}Audit: every call is attributed to the key and the person who issued it.

Model Context Protocol

Give an agent a seat at the calendar.

The MCP server speaks JSON-RPC 2.0 over Streamable HTTP at POST {{ api_base_url }}/mcp and implements initialize, tools/list, tools/call and ping. Connect with a bearer key, or let a native connector such as Claude Desktop sign in through the built-in OAuth 2.1 server with dynamic client registration and PKCE.

Claude Code
claude mcp add --transport http sm-bean \
  "{{ api_base_url }}/mcp" \
  --header "Authorization: Bearer bb_studio_…"
