Features

Everything a social team does in a week, in one tab.

From the first idea to the last reply. Every feature below is available to every user on every workspace. There is no premium tier.

Content composer

Write once, publish natively

Pick the accounts, write the post, and watch a live preview render for each platform with its own character limit. Anything that needs to differ, from the caption to the media to a Pinterest board or YouTube title, is an override on that platform alone.

  • {% include "marketing/_icon.html" with name="check" %}Per-platform overrides for caption, media, first comment and platform-specific settings.
  • {% include "marketing/_icon.html" with name="check" %}Templates, categories and tags so recurring formats take seconds and the calendar stays filterable.
  • {% include "marketing/_icon.html" with name="check" %}Version history on every post, plus a "next available slot" button that files it into the queue.
  • {% include "marketing/_icon.html" with name="check" %}Media library and Unsplash search inside the editor. Drag, drop, reorder.
publish · calendar
Calendar & scheduling

A calendar that fills itself

Set recurring weekly posting slots for each account, such as Instagram on Tuesday and Thursday mornings, then add posts to a named queue. Each one takes the next free slot automatically. Prefer to drag things around? The month, week and list views support that too.

  • {% include "marketing/_icon.html" with name="check" %}Posting slots and queues per account, with posts auto-assigned to the next opening.
  • {% include "marketing/_icon.html" with name="check" %}Recurring posts on daily, weekly or monthly rules, and custom events like launches or campaigns on the same calendar.
  • {% include "marketing/_icon.html" with name="check" %}Status at a glance: draft, pending review, approved, scheduled, publishing, published, partially published or failed.
  • {% include "marketing/_icon.html" with name="check" %}Filters by channel, tag and status, in the workspace's own time zone.
create · ideas
Idea board

Somewhere for half-formed ideas

A Kanban board for each workspace where ideas, briefs and reference material wait until they are ready. Attach media and tags early, then promote an idea straight into the composer when it is time.

  • {% include "marketing/_icon.html" with name="check" %}Drag between columns to move an idea from backlog to in-progress to done.
  • {% include "marketing/_icon.html" with name="check" %}Attach media and notes so the eventual post starts with everything it needs.
  • {% include "marketing/_icon.html" with name="check" %}One click to a draft that keeps the idea's title, description and attachments.

Approvals & client portal

Sign-off without the email chain

Each workspace picks its own flow: no approvals, optional, internal only, or internal followed by client. Internal comments stay internal. Clients get a passwordless 30-day link to a portal where they approve, reject or comment, without creating an account.

  • {% include "marketing/_icon.html" with name="check" %}Configurable stages per workspace, from none to two-step internal plus client.
  • {% include "marketing/_icon.html" with name="check" %}Threaded comments with attachments, marked internal or visible to the client.
  • {% include "marketing/_icon.html" with name="check" %}Reminders and a full audit trail of who approved what, and when.

Unified social inbox

Every conversation, one queue

Comments, mentions, direct messages and reviews from every connected platform arrive in a single inbox. Triage by sentiment, assign to a teammate, reply in a thread, and never wonder whether a comment was missed.

  • {% include "marketing/_icon.html" with name="check" %}Sentiment analysis and assignments so the unhappy customer gets a human first.
  • {% include "marketing/_icon.html" with name="check" %}Threaded replies sent through the platform's own API, with draft replies you can hand off.
  • {% include "marketing/_icon.html" with name="check" %}Real-time webhooks for Facebook, Instagram and Threads, a polling fallback for the rest, and a backfill command to import history.

Analytics

Reporting straight from the platforms

No estimates, no scraping. Each connected account's native insights API feeds KPI cards and trend charts over 7, 30 or 90 days, and a sortable table shows how every single post performed.

  • {% include "marketing/_icon.html" with name="check" %}Channel-level metrics: followers, reach, views, watch time and engagement rate with period-over-period change.
  • {% include "marketing/_icon.html" with name="check" %}Per-post metrics with the platform-specific breakdown behind each number.
  • {% include "marketing/_icon.html" with name="check" %}Same data over the API for your own dashboards and reports.

Media library

Upload once, get every size

Organisation-wide and workspace-scoped libraries with nested folders keep client assets apart. Each upload gets platform-optimised variants generated automatically, alt text travels with the asset, and large video is streamed rather than buffered.

  • {% include "marketing/_icon.html" with name="check" %}Nested folders and search across images and video, by name, type and tag.
  • {% include "marketing/_icon.html" with name="check" %}Local disk or any S3-compatible bucket (Cloudflare R2, AWS S3, Backblaze B2, MinIO).
  • {% include "marketing/_icon.html" with name="check" %}Uploads up to 1 GB with FFmpeg handling video processing on the server.

Multi-workspace & teams

Built for many clients under one roof

An organisation holds as many workspaces as you have brands. Each workspace has its own channels, calendar, inbox, library, approval flow, branding and defaults. Members are invited per workspace with exactly the permissions they need.

  • {% include "marketing/_icon.html" with name="check" %}Owner, admin, editor, viewer and client roles, plus custom roles built from granular permissions.
  • {% include "marketing/_icon.html" with name="check" %}Invitations by email and Google single sign-on.
  • {% include "marketing/_icon.html" with name="check" %}Workspace defaults for hashtags, first comments and posting templates, so new posts start right.
