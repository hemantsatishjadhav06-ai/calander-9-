Self-hosting

Production on a VPS in four commands

Docker Compose brings up Gunicorn, the background worker, PostgreSQL and Caddy. Migrations run automatically on start, and Tailwind builds inside the image.

On your server
git clone <your-repository-url> sm-bean
cd sm-bean
cp .env.example .env
# edit .env: SECRET_KEY, ALLOWED_HOSTS, APP_URL
# and DATABASE_URL pointing at the postgres service
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
docker compose exec app python manage.py createsuperuser
To update later
git pull
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
  • {% include "marketing/_icon.html" with name="check" %}Point your domain at the server and set it in the Caddyfile. Caddy fetches the certificate.
  • {% include "marketing/_icon.html" with name="check" %}Media is served by Caddy straight from the volume, so large video never occupies an app worker.
  • {% include "marketing/_icon.html" with name="check" %}Email for invitations and password resets is any SMTP server; set the EMAIL_* variables.
  • {% include "marketing/_icon.html" with name="check" %}Platform apps are registered once per network; the README walks through Meta, LinkedIn, TikTok, Google and Pinterest step by step, including the exact redirect URIs.
  • {% include "marketing/_icon.html" with name="check" %}Optional extras: Google SSO, Unsplash search, Sentry, S3-compatible storage.

Ephemeral platforms need object storage. Railway, Render and Heroku reset their disks on deploy, so set STORAGE_BACKEND=s3 with an S3-compatible bucket before uploading media there.

Local development

Runs on a laptop with SQLite

No Docker and no database server needed for development. Python 3.12+ and Node 20+ are the only prerequisites.

  • {% include "marketing/_icon.html" with name="check" %}Set DATABASE_URL=sqlite:///db.sqlite3 in .env
  • {% include "marketing/_icon.html" with name="check" %}Three terminals: Tailwind watcher, Django server, background worker
  • {% include "marketing/_icon.html" with name="check" %}pytest, ruff and mypy are wired up, with CI running all three
Local setup
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
(cd theme/static_src && npm install)
python manage.py migrate
python manage.py createsuperuser

# three terminals
(cd theme/static_src && npm run start)
python manage.py runserver
python manage.py process_tasks
